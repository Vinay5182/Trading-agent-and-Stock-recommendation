# `paper_signals` Collection Schema & Lifecycle Specification

Complete architectural documentation for the `paper_signals` MongoDB collection in `trading_agent_clean`.

---

## 1. Collection Purpose

`paper_signals` tracks every trade setup signal generated by technical confirmation pipelines (e.g. Swing TV Confirmed, Momentum TV Confirmed). It serves as the primary bridge between raw TradingView confirmations (`saved_tv_confirmations`), risk-managed paper trade execution (`paper_trades`), and AI machine-learning datasets (`decision_outcome_dataset.py`, `daily_dataset.py`).

---

## 2. Schema Definition & Field Classifications

### A. Identity & Core Metadata (Required)
- `_id`: `ObjectId` — Unique MongoDB document primary key.
- `setup_id`: `string` — Canonical setup identifier (e.g. `paper_setup:v2:0db2511375d2624bcf41c4b4a`).
- `symbol`: `string` — Standard exchange ticker symbol (e.g. `TORNTPHARM`).
- `tradingview_symbol`: `string` — Full TradingView symbol identifier (e.g. `NSE:TORNTPHARM`).
- `timeframe`: `string` — Chart timeframe (`1D`, `4H`, `1H`).
- `signal_type`: `string` — Originating signal strategy type (`SWING_TV_CONFIRMED`, `MOMENTUM_TV_CONFIRMED`).
- `source`: `string` — Source collection indicator (`saved_tv_confirmations`).
- `source_confirmation_id`: `string` — Foreign key link to source TradingView confirmation document.

### B. Status & State Machine (Required / Runtime)
- `status`: `string` — Signal lifecycle state (`WAITING_FOR_ENTRY`, `ACTIVE`, `COMPLETED`, `SL_HIT`, `EXPIRED`, `CANCELLED`, `WAITING_FOR_CAPITAL`).
- `entry_readiness`: `string` — Readiness indicator (`READY`, `WAITING`).
- `next_action`: `string` — Pipeline next step recommendation (`PAPER_PLAN_READY`).
- `paper_only`: `boolean` — Safety lock indicator (Always `true`).
- `state_version`: `integer` — Schema version identifier (Default `1`).

### C. Execution & Risk Parameters (Required)
- `entry_price`: `float` — Target entry trigger price.
- `stop_loss`: `float` — Stop loss execution price.
- `target_1`: `float` — Target 1 exit price (1.0R).
- `target_2`: `float` — Target 2 exit price (2.0R).
- `target_3`: `float` — Target 3 exit price (3.0R).
- `risk_per_share`: `float` — Share risk distance (`abs(entry_price - stop_loss)`).
- `risk_reward`: `float` — Risk-to-reward ratio for Target 1.
- `trade_quality_grade`: `string` — Quantitative quality grade (`A_PLUS`, `A`, `B`).
- `final_quantity`: `integer` — Calculated share allocation quantity.

### D. Historical Backward-Compatibility Field Aliases (Kept for Downstream Consumers)
To prevent breaking existing API responses, frontend rendering, or ML dataset builders, the following duplicate aliases are populated on write:
- `canonical_setup_id` $\leftrightarrow$ `setup_id`
- `source_signal_type` $\leftrightarrow$ `signal_type`
- `next_action_for_paper_trade` $\leftrightarrow$ `next_action`
- `entry`, `paper_entry_price` $\leftrightarrow$ `entry_price`
- `sl`, `paper_stop_loss`, `final_stop_loss` $\leftrightarrow$ `stop_loss`
- `paper_target_1`, `t1`, `t1_target_final`, `t1_target_raw` $\leftrightarrow$ `target_1`
- `paper_target_2`, `t2`, `t2_target_final`, `t2_target_raw` $\leftrightarrow$ `target_2`
- `paper_target_3`, `t3`, `t3_target_final`, `t3_target_raw` $\leftrightarrow$ `target_3`
- `paper_risk_per_share` $\leftrightarrow$ `risk_per_share`
- `rr`, `paper_rr_1` $\leftrightarrow$ `risk_reward`
- `avoid_condition` $\leftrightarrow$ `invalidation_condition`

### E. Reserved & Future Feature Fields (Nullable)
- `stop_loss_override_reason`: `string | null` — Populated only when manual SL override is active.
- `t1_structure_timestamp`, `t1_structure_zone_lower`, `t1_structure_zone_upper`: `null` — Reserved for future order-book structure integration.
- `t2_structure_timestamp`, `t2_structure_zone_lower`, `t2_structure_zone_upper`: `null` — Reserved for future order-book structure integration.
- `t3_structure_timestamp`, `t3_structure_zone_lower`, `t3_structure_zone_upper`: `null` — Reserved for future order-book structure integration.

## 3. Signal Lifecycle & State Machine

```
TradingView Confirmation
        │
        ▼ (sync_trade_ready)
paper_signal Created (status = WAITING_FOR_ENTRY)
        │
        ▼ (Position Sizing & Capital Allocation)
Promotion to paper_trade (status = WAITING_FOR_ENTRY / ACTIVE)
        │
        ▼ (Campaign Snapshot / System Reset)
Archived (archived_at, snapshot_id populated)
```
